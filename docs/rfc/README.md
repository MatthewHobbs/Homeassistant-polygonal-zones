# RFCs

A **request for comments** is where a proposal is thought through: the problem, the options with
their costs, and a recommendation. An ADR (`docs/adr/`) is where the decision is committed. The
RFC text is not published in this repository; this index records what was proposed and decided.

| #    | Title                                                  | Status  | Decided    | ADR                                             |
| ---- | ------------------------------------------------------ | ------- | ---------- | ----------------------------------------------- |
| 0001 | Detecting and refreshing stale trackers ([#110][i110]) | Decided | 2026-10-20 | [ADR 0003](../adr/0003-last-reported-sensor.md) |

Status is one of **Draft**, **Decided**, **Withdrawn** or **Superseded**. A withdrawn RFC stays
listed: it records what was considered and why it lost.

[i110]: https://github.com/MatthewHobbs/Homeassistant-polygonal-zones/issues/110
