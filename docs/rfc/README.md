# RFCs

A **request for comments** is where a proposal is thought through: the problem, the options with
their costs, and a recommendation. An ADR (`docs/adr/`) is where the decision is committed. RFCs
live as docs so they can be read and commented on without a PR per draft; this index is the part
that lives in git, so what was decided survives even if a doc is deleted. The copy in git is
authoritative, and an RFC authorises nothing.

| ---- | ------------------------------------------------------ | ------ | ------- | --------------------------------------------------------------------------- | ---- |
| 0001 | Detecting and refreshing stale trackers ([#110][i110]) | Draft  |         | doc | none |

Status is one of **Draft**, **Decided**, **Withdrawn** or **Superseded**. A withdrawn RFC stays
listed: it records what was considered and why it lost.
