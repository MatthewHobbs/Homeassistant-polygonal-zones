# Polygonal Zones

Report the zone a Home Assistant `device_tracker` entity is in, using polygons you draw on a map.

- Zones come from HTTP(S) addresses or files under `/config`.
- Where zones overlap, an optional priority decides the winner.
- Actions add, edit, delete and replace zones.

[Full documentation](https://matthewhobbs.github.io/Homeassistant-polygonal-zones/) covers installation, the zone file format and privacy. The [GitHub README](https://github.com/MatthewHobbs/Homeassistant-polygonal-zones#readme) has the source and issue tracker.
